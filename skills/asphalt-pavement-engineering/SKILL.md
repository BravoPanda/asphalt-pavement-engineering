# 沥青路面工程全流程专业技能 (Asphalt Pavement Engineering Skill)

本技能为高速公路及高等级公路沥青路面工程的全生命周期一体化专业指南，全面打通**配合比设计**、**现场施工工艺控制**与**工程内业试验数据合规核验**三大核心板块，满足中国现行交通运输行业标准（JTG系列）与高品质工程建造要求。

## 二、第一板块：沥青混合料配合比设计全流程

### 1. 三阶段配合比设计流程
1. **目标配合比设计（Target Mix Design）**：
   - 优选原材料（粗集料、细集料、矿粉、沥青结合料、改性剂或纤维）。
   - 室内筛分计算确定矿料级配范围与目标曲线。
   - 制作马歇尔试件确定最佳沥青用量（$OAC$）。
   - 进行路用性能检验（高温抗车辙、低温弯曲抗裂、水稳定性、渗水等）。
2. **生产配合比设计（Production Mix Design）**：
   - 对拌和楼二次筛分后的各热料仓集料进行筛分取样。
   - 确定各热料仓配料比例及最佳沥青用量。
3. **生产配合比验证阶段（Production Verification）**：
   - 试拌试铺试验段（一般 $100 \sim 200\text{ m}$），取样检验配合比自洽性。
   - 确定施工标准配合比与压实标准密度（马歇尔标准密度与最大理论密度双控基准）。

### 2. 集料级配加权合成计算
标准筛孔：`37.5, 31.5, 26.5, 19, 16, 13.2, 9.5, 4.75, 2.36, 1.18, 0.6, 0.3, 0.15, 0.075 mm`。
合成通过率计算：
$$P_j = \sum_{i=1}^n \left( \frac{X_i \times P_{ij}}{100} \right)$$
其中 $X_i$ 为第 $i$ 仓集料比例（$\sum X_i = 100\%$），$P_{ij}$ 为该仓在筛孔 $j$ 的通过率。

### 3. 体积指标核心计算公式
1. **集料合成毛体积相对密度 ($\gamma_{sb}$)**：
   $$\gamma_{sb} = \frac{100}{\sum_{i=1}^{n} \frac{P_i}{\gamma_{sbi}}}$$
2. **理论最大相对密度 ($\gamma_t$)**：
   $$\gamma_t = \frac{100}{\frac{P_s}{\gamma_{se}} + \frac{P_b}{\gamma_b}}$$
   式中：$P_s = 100 - P_b$；$P_b$ 为沥青用量（%）；$\gamma_b$ 为沥青相对密度（25℃）；$\gamma_{se}$ 为集料有效相对密度。
3. **试件毛体积相对密度 ($\gamma_f$)**：
   - 表干法（吸水率 $\le 2.0\%$）：$\gamma_f = \frac{m_a}{m_f - m_w}$
   - 水中重法（吸水率 $< 0.5\%$）：$\gamma_f = \frac{m_a}{m_a - m_w}$
4. **试件空隙率 ($VV$)**：
   $$VV = \left(1 - \frac{\gamma_f}{\gamma_t}\right) \times 100\%$$
5. **矿料间隙率 ($VMA$)**：
   $$VMA = \left(1 - \frac{\gamma_f}{\gamma_{sb}} \times \frac{P_s}{100}\right) \times 100\%$$
6. **沥青有效饱和度 ($VFA$)**：
   $$VFA = \frac{VMA - VV}{VMA} \times 100\%$$

### 4. 路用性能关键指标门槛
- **高温稳定性**：60℃车辙试验动稳定度 $DS \ge 2800 \sim 3000\text{ 轮/mm}$（改性沥青/重载交通可要求 $\ge 5000\text{ 轮/mm}$）。
- **水稳定性**：48h 浸水马歇尔残留稳定度 $MS_0 \ge 85\%$；冻融劈裂强度比 $TSR \ge 80\%$。
- **低温抗裂**：-10℃ 弯曲试验破坏应变 $\epsilon_B \ge 2500 \sim 2800\,\mu\epsilon$。
- **渗水防渗**：密级配沥青混合料渗水系数 $C_w \le 80 \sim 120\text{ mL/min}$；SMA $\le 200\text{ mL/min}$。
- **SMA专用**：谢伦堡析漏损失 $\le 0.1\%$，肯塔堡飞散损失 $\le 15\%$。

## 三、第二板块：高速公路现场施工工艺与质量控制

### 1. 全施工过程温控体系（核心红线）
| 施工阶段 | 普通石油沥青 (AC) | SBS改性沥青 (AC/SMA) | 控制要点 |
| :--- | :--- | :--- | :--- |
| **沥青加热温度** | 150℃ ~ 160℃ | 160℃ ~ 170℃ | 严防局部过热老化 |
| **矿料加热温度** | 160℃ ~ 180℃ | 185℃ ~ 195℃ | 高于沥青温度 10~15℃ |
| **混合料出料温度** | 140℃ ~ 165℃ | 170℃ ~ 185℃ | 超过 195℃ 必须废弃 |
| **运抵现场温度** | $\ge 140$℃ | $\ge 165$℃ | 双层保温帆布严密覆盖 |
| **开始摊铺温度** | $\ge 135$℃ | $\ge 160$℃ | 低温施工要求 $\ge 165$℃ |
| **初压开始温度** | 130℃ ~ 140℃ | 150℃ ~ 165℃ | 紧跟摊铺机，高温静压/轻振 |
| **复压开始温度** | 100℃ ~ 120℃ | 130℃ ~ 140℃ | 密实核心，重型机械组合排压 |
| **终压结束温度** | $\ge 70$℃ | $\ge 90$℃ | 双钢轮静压消除轮迹 |
| **开放交通温度** | 路表温度 $< 50$℃ | 路表温度 $< 50$℃ | 冷却彻底，防止早期车辙 |

### 2. 摊铺工艺关键控制
- **设备配置**：双机梯队联合摊铺（前后错开 10~20m，搭接 3~6cm 热接缝）或宽幅抗离析单机全幅摊铺。
- **基准控制**：中下层采用钢丝绳挂线或高精度滑靴；表面层采用非接触式多点平衡梁或移动式激光扫平梁。
- **匀速连续作业**：摊铺速度恒定在 $1.5 \sim 2.5\text{ m/min}$，运料车在机前 10~30cm 挂空挡，严禁冲撞摊铺机。

### 3. 压实组合与平接缝规程
- **初压**：11~13t 双钢轮压路机静压或轻振 1~2 遍，驱动轮朝向摊铺机。
- **复压**：26~30t 胶轮压路机揉搓密实（SMA严禁胶轮，应全部采用大吨位双钢轮振动压路机高频低幅碾压）4~6 遍。
- **终压**：双钢轮压路机静压 2~3 遍，直至轮迹完全消失。
- **横向平接缝**：必须使用 3m 直尺检测端部平整度，用切割机垂直锯缝清除厚度不足部分，切面涂刷粘层油，压路机先横向起压再顺向推进。

### 4. 现场交竣工验收指标 (JTG F80/1-2017)
- **压实度**：马歇尔试验密度比 $\ge 96\%$（改性沥青 $\ge 98\%$）；试验段最大理论密度比 $\ge 93\%$（改性沥青 $\ge 94\%$）。
- **平整度**：激光平整度仪 $IRI \le 1.0 \sim 1.2\text{ m/km}$；连续式平整度仪 $\sigma \le 0.8 \sim 1.0\text{ mm}$。
- **抗滑特性**：构造深度 $TD \ge 0.55 \sim 0.8\text{ mm}$（SMA $\ge 0.7 \sim 1.1\text{ mm}$）；摩擦系数 $BPN \ge 45$。

## 四、第三板块：内业资料与试验数据合规核验（六维审核体系）

### 1. 六维递进核验链条
```
[1. 完整性闭环] ──> [2. 物理可行性审查] ──> [3. 内部公式自洽勾稽]
                                                      │
[6. 评级归档输出] <── [5. 统计离散与防伪指纹] <── [4. 跨表协同一致性]
```

### 2. 核心核验指标与容差控制
| 核验项目 | 校验关系 / 公式 | 合格容差 $|\Delta|$ | 异常判定规则 |
| :--- | :--- | :--- | :--- |
| **毛体积相对密度** | $\gamma_f = m_a / (m_f - m_w)$ | $\le 0.004$ | 实测与表内填写偏差超标 |
| **理论最大密度** | $\gamma_t = 100 / (P_s/\gamma_{se} + P_b/\gamma_b)$ | $\le 0.004$ | 必须满足 $\gamma_t > \gamma_f$ |
| **空隙率 $VV$** | $VV = (1 - \gamma_f / \gamma_t) \times 100\%$ | $\le 0.15\%$ | 必须 $VV > 0$，超标判定公式不自洽 |
| **间隙率 $VMA$** | $VMA = (1 - \frac{\gamma_f}{\gamma_{sb}} \times \frac{P_s}{100}) \times 100\%$ | $\le 0.15\%$ | 必须 $VMA > VV$，违背为严重物理缺陷 |
| **饱和度 $VFA$** | $VFA = (VMA - VV) / VMA \times 100\%$ | $\le 0.35\%$ | 必须在 $0\% \sim 100\%$ 范围 |
| **合成级配** | $P_j = \sum (X_i \times P_{ij}) / 100$ | $\le 0.20\%$ | 各仓加权和与汇总表不一致 |

### 3. 数据真实性与造假指纹识别算法
- **超常同质性与零方差**：真实室内试验必然存在称重与试件制作离散。若一组平行试件数据完全相同（零方差）或 $CV < 0.05\%$，触发造假警示。
- **格拉布斯极值剔除 (Grubbs' Test)**：在 $\alpha = 0.05$ 显著性水平下计算 $G = \frac{|x_i - \bar{x}|}{s}$，对离群可疑点按规程复核。
- **等差数列构造指纹**：检测平行试件读数是否呈现人为等差步长（如 2.451, 2.453, 2.455, 2.457）。
- **时间逻辑链审查**：原材料进场日期 $\le$ 试验委托日期 $\le$ 试件成型日期 $\le$ 养护龄期截止日期 $\le$ 试验检测日期 $\le$ 报审批准日期。
