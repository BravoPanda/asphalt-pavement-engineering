# 沥青材料基因组设计原理与初始油石比推导说明

## 一、什么是沥青路面材料基因组设计 (Asphalt MGE)？

材料基因组工程（Materials Genome Engineering）的核心在于建立 **“材料基因（成分/岩性/骨架）→ 工艺参数 → 体积与力学性能 → 服役环境”** 的可计算映射关系，通过正向虚拟筛选大幅减少室内盲目试拌的轮次与成本。

本技能库将沥青混合料拆解为 4 个结构化 JSON 基因层（位于 `genome/` 目录）：
1. **结合料基因 (`binders.json`)**：相对密度 $\gamma_b$、PG 分级、黏度/类型油石比修正、拌和与碾压温控窗口。
2. **集料岩性基因 (`aggregates.json`)**：毛体积密度 $\gamma_{sb}$、表观密度 $\gamma_{sa}$、吸水率 $w_x$、酸碱性（$\text{SiO}_2$ 粘附倾向）、磨光值 PSV 及工程风险标签。
3. **级配骨架基因 (`gradations.json`)**：JTG 规范上下限、公称最大粒径 NMAS、目标有效沥青膜厚度 $DA$、空隙率/VMA/VFA/粉胶比限值、纤维默认掺量。
4. **环境与荷载基因 (`environments.json`)**：气候分区与交通荷载对油石比及路用性能门槛的修正权重。

## 二、机理 + 经验双驱动初始油石比推荐模型

在 `scripts/oac_recommender.py` 中，初始油石比 $P_{a0}$ 的推荐采用**体积等效 + 表面积膜厚 + 吸水率吸收补偿 + 结合料/环境修正**四级计算链：

### 1. 基准有效油石比 ($P_{ae,0}$)
- **若输入了实测合成级配**：按 JTG F40 表面积系数法计算集料总比表面积 $SA$（$\text{m}^2/\text{kg}$）：
  $$SA = \frac{0.41 + 0.41 P_{4.75} + 0.82 P_{2.36} + 1.64 P_{1.18} + 2.87 P_{0.6} + 6.14 P_{0.3} + 12.29 P_{0.15} + 32.77 P_{0.075}}{100}$$
  结合该级配类型的目标有效沥青膜厚度 $DA$（$\mu\text{m}$），由物理机理公式反推有效沥青用量，并与规范经验基准加权融合（降低极端筛分偏差）。
- **若仅选择级配类型**：直接采用 `gradations.json` 中的基准有效油石比。

### 2. 集料密度体积等效修正
基准油石比对应标准集料密度 $\gamma_{sb,0} = 2.70$（如石灰岩）。当更换为高密度玄武岩（$\approx 2.88$）或超高密度钢渣（$\approx 3.28$）时，相同体积的沥青膜在质量比上必须折减：
$$P_{ae,\text{dens}} = P_{ae,0} \times \frac{\gamma_{sb,0}}{\gamma_{sb}} \times \frac{\gamma_b}{\gamma_{b,0}}$$

### 3. 集料吸水率与沥青吸收补偿 ($P_{ba}$)
根据集料吸水率 $w_x$ 与 JTG 吸收系数经验式：
$$C = \text{clamp}(0.033 w_x^2 - 0.2936 w_x + 0.9339,\ 0.35,\ 0.90)$$
$$P_{ba} \approx C \cdot w_x \cdot \frac{\gamma_b}{1.0}$$
计算超出基准石灰岩吸水率（$0.55\%$）部分的额外沥青吸收补偿 $\Delta P_{ba}$，避免多孔玄武岩、钢渣因过度吸油导致有效沥青膜偏薄、混合料发干松散。

### 4. 结合料、纤维与气候荷载修正
叠加结合料黏度/类型修正（如 SBS、橡胶沥青 AR、高粘 HVA）、纤维吸油修正（SMA 每掺 $0.3\%$ 木质素纤维约需额外 $+0.25\%$ 油石比）以及气候/交通微调，输出最终推荐初始油石比 $P_{a0}$、对应沥青含量 $P_{b0}$ 及 **5 组马歇尔试拌油石比梯度**，并自动触发岩性-结合料配伍风险预警。
