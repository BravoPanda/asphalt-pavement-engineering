# JTG 行业规范关键技术指标速查表

## 一、沥青路面马歇尔试验技术标准 (JTG F40-2004 表 5.3.3-1)
| 试验项目 | 单位 | 高速、一级公路技术要求 |
| :--- | :--- | :--- |
| **击实次数** | 次 | 双面各 75 次（大型马歇尔各 112 次） |
| **稳定度 MS** | kN | $\ge 8.0$（改性沥青 $\ge 10.0$） |
| **流值 FL** | mm | $1.5 \sim 4.0$（改性沥青 $2.0 \sim 4.0$） |
| **设计空隙率 VV** | % | AC-13/16/20: $3.0 \sim 5.0$；SMA-13: $3.0 \sim 4.5$ |
| **矿料间隙率 VMA** | % | AC-13: $\ge 14.0$；AC-16: $\ge 13.5$；AC-20: $\ge 13.0$；SMA-13: $\ge 16.5$ |
| **沥青饱和度 VFA** | % | AC: $65 \sim 75$ (中下层可放宽至 70~85)；SMA: $75 \sim 85$ |

## 二、路用性能检验标准 (JTG F40-2004)
1. **车辙试验动稳定度 (DS)**：
   - 普通沥青 AC：$\ge 800 \sim 1000\text{ 轮/mm}$
   - 改性沥青 AC/SMA：$\ge 2800 \sim 3000\text{ 轮/mm}$（夏炎热交通繁重区要求 $\ge 5000\text{ 轮/mm}$）
2. **水稳定性**：
   - 48h 浸水马歇尔残留稳定度 $MS_0 \ge 85\%$
   - 冻融劈裂试验强度比 $TSR \ge 80\%$
3. **低温弯曲试验破坏应变 ($\epsilon_B$)**：
   - 试验温度 -10℃，加载速率 50mm/min
   - 冬季严寒区：$\ge 2800 \sim 3000\,\mu\epsilon$
   - 冬季寒冷区：$\ge 2500\,\mu\epsilon$
   - 冬季温和区：$\ge 2000\,\mu\epsilon$
4. **渗水系数**：
   - 密级配 AC $\le 120\text{ mL/min}$（现场施工允许放宽至 $150\text{ mL/min}$）
   - SMA $\le 200\text{ mL/min}$
